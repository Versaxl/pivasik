# Изображения

Положите сюда:
- `favicon.ico` — иконка сайта (32×32 или 64×64)
- `logo.png` — логотип (рекомендуется 512×512, прозрачный фон)

## backgrounds/
- `summer.jpg` — светлый летний фон (1920×1080)
- `night.jpg` — тёмный ночной фон (1920×1080)

Используются как опциональные фоны. Сейчас стили работают на градиентах
без картинок — можно добавить позже.
